# Disney LaTeX Symbols

A LaTeX package for using stylized commands that represent Disney character icons. 
This lightweight package allows you to insert custom macros like `\mickey`, `\minnie`, etc., in your LaTeX documents.

## ✨ Features
- Easy to use commands for various Disney characters
- Plug-and-play: just load the `.sty` file and go
- Ideal for kids’ documents, educational posters, themed games, and more

## 📦 Installation
1. Clone or download this repository.
2. Place `disney_symbols.sty` in your LaTeX project directory.
3. In your `.tex` file, add:
   ```latex
   \usepackage{disney_symbols}
   ```

## 🧪 Example
See `example.tex` for a full example. To compile:
```bash
pdflatex example.tex
```
